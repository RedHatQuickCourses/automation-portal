== Execution Environment CI/CD Architecture

The main idea is to treat the Execution Environment (EE) definition as code. Instead of managing EEs manually through the portal, we store the definition and its dependencies in Git. This provides **version control, consistency, auditability, and reproducibility**, while allowing the EE build and publishing process to be automated through a **CI/CD pipeline**.

Overall, this creates an automated flow from **Git change → CI/CD pipeline → `ansible-builder` → container image → registry → Ansible Automation Platform**, reducing manual effort while improving consistency and traceability.
